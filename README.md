# Hi, I'm Makmot Robin

I like turning unfinished exercises into things that actually build, test and run.
Most of what is here started as coursework, the difference is that every public
project now compiles from a clean checkout and has tests.

## What's here

| Repository | What it is |
| --- | --- |
| [Torrent](https://github.com/MakmotRobin/Torrent) | A desktop BitTorrent client built with Electron and WebTorrent, with a 110-test suite and CI on Node 20 and 22 |
| [java-practice](https://github.com/MakmotRobin/java-practice) | Java and SQL exercises consolidated into one Maven project: 51 classes, 72 JUnit 5 tests, SQL scripts checked against H2, CI on Java 17 and 21 |
| [Suggestion_box](https://github.com/MakmotRobin/Suggestion_box) | A PHP/MySQL suggestion box for students, with admin feedback on a notice board |
